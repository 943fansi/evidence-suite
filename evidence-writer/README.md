# evidence-writer · 证据驱动写作方

从原 `evidence-proposal` 单流水线按「编写 / 审核」职责拆出的**写作侧 skill**，与 `evidence-reviewer`（审核方）形成对抗循环。

## 职责（写作者侧阶段）

| 生产阶段 | 全局阶段 | 动作 | 产物 | 对抗交接 |
|---------|---------|------|------|---------|
| w1 | 0 文档适配 | 定类型/结构/约束 | `00_topic.md` | — |
| w2 | 1 来源检索 | 联网检索 + 结构化 | `02_raw_sources.json` | → 审核方 r1（全局2） |
| w3 | 3 验证语料（3a/3b/3c） | PDF 下载 + 校验 + 抽取 | `04_validated_sources.json` + PDF/txt | — |
| w4 | 4 证据图谱 | 论点↔来源映射 | `06_evidence_map.json` | → 审核方 r2（全局4b） |
| w5 | 5 起草 | 生成初稿 | `08_初稿.md` | → 审核方 r3+r4（全局5b+6） |
| w6 | 7 修订 | 按审查意见定向修订 | `11_定稿.md` | → 审核方 r5（全局8） |
| w7 | 7b humanizer（可选） | 文风修复 | `11_定稿.md` | — |
| w8 | 9 专家修订 | 按外部意见修订 | `14_专家修订稿.md` | → 审核方终审门 |
| w9 | 10 导出 + 定稿净化 | 运行脚本 + 视觉抽检 | PDF / DOCX + qa | — |

## 对抗纪律

- 不自我放行：每个"提交给审核方"列的阶段，未经 `evidence-reviewer` 判决不得前进。
- 只修观察到的失败：修订逐条响应审查意见，输出响应说明表。
- 对抗最多 2 轮，超限按审核方"终止意见"上报。
