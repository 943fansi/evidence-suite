# w8: Expert-Response Revision（专家修订，写作者侧 · 全局阶段 9）
> 服务全局管线 w8（专家修订，全局阶段 9）。


**Agent**: 本地执行（当前 assistant）  
**Input**: `11_定稿.md` + `12_外部专家意见.md` + `04_validated_sources.json` + `06_evidence_map.json`  
**Output**: `14_专家修订稿.md` + `13_审查意见响应说明.md`（追加一节）

## Prompt Template

```
请读取以下文件：
1. 11_定稿.md
2. 12_外部专家意见.md
3. 04_validated_sources.json
4. 06_evidence_map.json

任务：请根据《12_外部专家意见.md》修订《11_定稿.md》，输出新的修订版方案。

输出文件名：14_专家修订稿.md

重要原则：
1. 以外部专家意见为主要修订依据。
2. 不得新增未经资料支撑的外部事实、政策、标准、论文、案例或市场数据。
3. 不得为了迎合专家意见而编造证据。
4. 对专家指出但现有资料无法支撑的内容，不要硬写入正文，应写入"需补充调研清单"。
5. 对证据不足的强表述，要降级为谨慎表达。
6. 对过度承诺的指标，要改为"项目拟定指标""对标参考指标"或"待验证指标"。
7. 对工程/设备类文档，选型要避免"唯一确定选型"，改为"候选选型"或"待比选选型"（教育/社科类该条可忽略）。
8. 对预算内容，若无明确报价，只能保留预算框架、估算逻辑和询价计划。
9. 保持正文引用闭环，所有外部依据继续使用 [S1]、[S2] 形式。
10. 不要删除必要章节，除非专家意见明确指出结构冗余。

修订步骤：

第一步：解析专家意见
请先提取《12_外部专家意见.md》中的修改要求，按以下类型归类：
- 必须修改
- 建议修改
- 可暂缓修改
- 因资料不足无法直接修改

第二步：逐项判断能否修订
对于每条专家意见，请判断：
1. 是否有 04_validated_sources.json 中的证据支撑？
2. 是否在 06_evidence_map.json 的允许表达边界内？
3. 是否需要降级表达？
4. 是否应移入"需补充调研清单"？

第三步：修订正文

第四步：新增"专家意见响应说明"
在 `research_case/13_审查意见响应说明.md` 末尾追加一节（不混入 14_专家修订稿.md 正文）：

## 专家意见响应说明
| 专家意见类型 | 专家意见摘要 | 修订处理 | 修改位置 | 备注 |
修订处理：已修改 / 已降级表达 / 已移入补充调研清单 / 资料不足暂不写入正文 / 保留原表述并说明理由

第五步：输出修订版方案
直接输出完整 Markdown 修订版方案。

输出要求：
1. 只输出修订后的完整方案。
2. 不要额外输出解释。
3. 不要遗漏参考资料清单。
4. 不要破坏原有 [Sx] 引用编号。
5. 若删除或新增引用，请同步检查参考资料清单。
```
