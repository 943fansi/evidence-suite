# Significance Writing Guide

Use this reference when Stage 5 (Draft) encounters gap-adjacent candidates in the evidence map, or when self-review flags formulaic phrasing in significance/contribution sections.

## I. Forbidden Expressions (Anti-Patterns)

The following phrases signal template-filled writing and must be avoided in the final draft:

- "拓展了X的理论边界"
- "丰富了Y的应用场景"
- "可为Z提供参考" / "具有重要的参考价值"
- "填补了X的空白" (acceptable only if a specific source directly proves the gap exists)
- "具有重要的理论意义和实践意义" (this is a meta-commentary, not content — replace with the actual argument)
- "对...具有深远影响" (replace with specific, measurable impact)
- "在前人基础上" + 无具体引用 (must name which predecessor and what foundation)
- "本研究弥补了上述不足" (replace with "上面提到的X不足由Y机制解决，下文将在Z章中检验")

## II. Problem-Driven Narrative Structure

A strong significance section follows a specific logical chain, not a list of contribution points:

1. **Status quo boundary**: Name the current best method or framework (cite source). State what problem it reliably solves and under what conditions.
2. **Failure condition**: Specify the exact condition or scenario where that method stops working. This is the contradiction that drives the need for the present work.
3. **Why it fails**: Explain the structural reason for the failure — not "it's not perfect," but "its mechanism relies on X assumption, which is violated when Y happens."
4. **Present work's mechanism**: State what distinct mechanism or operational handle the present method provides that the existing method lacks. This is the innovation claim, and it must be specific enough to be testable.
5. **Why this mechanism crosses the boundary**: Close the logic by showing how the new mechanism specifically addresses the failure condition identified in step 2.

Example (from a completed draft, paraphrased):

> Gallahue's hourglass model [S50] provides a clear developmental sequencing framework — it tells educators *what* FMS milestones to expect at each age band. However, it provides no operational guidance on *how* to design activities that target specific skills while maintaining children's engagement and matching their cognitive-developmental stage. This is the boundary where the hourglass model runs out: it is a diagnostic and normative framework, not a design methodology. Newell's constraint model [CAT1-05] fills this exact gap by decomposing any motor task into three adjustable dimensions (task, environment, individual constraints), giving the teacher three concrete levers rather than one abstract milestone. The present work synthesizes these two frameworks: Gallahue provides the *target* (which FMS at which age), Newell provides the *method* (which constraints to manipulate to achieve that target in a game format).

## III. Theory-Selection Narrative Checklist

Before finalizing a section that introduces a major theory, verify each of these four questions is answered in the prose:

1. **Why this theory, not the obvious alternative?** (Name the alternative explicitly — readers who know the field will be thinking of it.)
2. **What specific mechanism or operational handle does this theory provide that the alternative lacks?** (Must be concrete — a concept, a variable, a classification, a procedure — not "a broader perspective.")
3. **What is the cost of using this theory?** (Every theoretical choice has a blind spot. Acknowledge the scope condition or limitation of the chosen framework in one sentence.)
4. **Where does this theory's mechanism become visible in the present work's design?** (Point to a specific chapter/section/table — show, don't just claim.)
