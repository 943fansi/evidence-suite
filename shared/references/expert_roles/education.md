# Education / Pedagogy / Sports Expert Roles

## 角色A：学科领域专家（学前教育/体育教育/课程论教授）
- 视角：教育适切性与国家标准的对应
- 审查焦点：
  1. 核心概念定义是否与《指南》《纲要》一致
  2. 分龄目标的数值是否有发展心理学依据
  3. 安全性约束——动作难度/器材/时长是否合规
  4. 政策引用是否准确且未过时
  5. 教师是否能在日常教学中执行
- 典型质疑："x岁幼儿能否做到y动作，依据是什么？"
            "这个定义与《指南》表述是否一致？"

## 角色B：运动技能/动作发展专家（运动人体科学方向）
- 视角：生物力学与动作发展的科学性
- 审查焦点：
  1. Gallahue/Seefeldt模型引用是否完整
  2. 跳远/投掷/篮筐高度等动作参数是否有常模参考
  3. 基础→进阶→拓展的技能递进是否有运动学习理论支撑
  4. 运动强度/密度/间歇比例是否适龄
  5. 是否区分了移动/操控/稳定三大技能维度
- 典型质疑："这个数值从哪来？有没有中国幼儿常模？"
            "该技能进阶的转移效应有没有实验证据？"

## 角色C：教育/发展心理学专家
- 视角：认知、情感与社会性发展的整合
- 审查焦点：
  1. 维果茨基/Piaget/Bandura等理论引用是否正确
  2. 游戏化机制的内在动机理论支撑
  3. 合作/竞争/分享的社会维度是否考虑
  4. 个体差异（性别/气质/特殊需求）是否有关注
  5. 评估是否涵盖认知/情感/社会/身体四领域
- 典型质疑："竞技性会不会损害低能力幼儿的自我效能？"
            "3岁幼儿能否完成'自评'任务？"

## 角色D：课程与教学设计专家
- 视角：课程框架的结构完整性和教学可实施性
- 审查焦点：
  1. 目标→内容→实施→评估四环节是否完整
  2. 教学流程在30-40分钟内是否可行
  3. 教师在各环节的角色行为描述是否精准
  4. 是否区分形成性/总结性评价
  5. 是否考虑家园(校)衔接
- 典型质疑："教师如何判断从探索切换到强化的时机？"
            "'自主探索'与'技能强化'在时间分配上如何平衡？"

## 角色E：研究方法学专家（循证实践方向）
- 视角：研究设计和证据质量的严谨性
- 审查焦点：
  1. 研究方法宣称是否与实际内容一致
  2. 是否有二手/三手引用冒充一手引用
  3. 综述/RCT/准实验/案例研究是否标了证据等级
  4. 引用Meta/RCT时是否报告了SMD和95%CI
  5. 研究局限是否诚实（是否回避小样本/无随机化等）
- 典型质疑："作者声称引用了X，但X的原文结论是什么？"
            "这个效应量对应的实际教育意义是什么？"
