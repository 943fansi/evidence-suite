# 定稿净化清单（Finalize Checklist）

正式交付前把工作稿（带 `[Sx]`/`[Gx]`/`[假设]`/`[待内部确认]` 脚手架）转成干净交付物。
`python scripts/finalize_draft.py` 自动完成下述机械步骤；本清单用于人工核对与脚本无法覆盖的语义检查。

> 触发时机：学位论文、期刊投稿、专利交底书、GF 报告等**正式交付物**，在阶段 9/10 之间必须执行一次；
> 交底书/申请草案等要求"投稿版零标记"的文档类型强制执行（见 `patent_writing_guide.md`）。

## 为什么必须净化（真实教训）

正式论文被评审退稿的典型"AI/脚手架痕迹"：

1. `[Sx]` / `[Gx]` / `[假设]` / `[待内部确认]` / `[待验证]` 直接出现在定稿正文。
2. 文档头部残留 `> **标记图例**：[Sx]=…；[Gx]=…` 图例行。
3. 残留 `references/thesis_format.md` 等 skill 内部路径。
4. 封面残留 `编号：2023xxxx[待内部确认]`、`资助项目：[待内部确认]`、`By XX / Supervisor: Prof. XXX`。
5. 附录 A"证据缺口清单"原样保留（表内出现 `NRC ADAMS PDF受反爬限制不可下载` 等爬虫/提示词痕迹）。
6. 引文编码 `[S1]` 而非标准顺序编码 `[1]`。

## 脚本处理的机械步骤（顺序敏感，勿手工重排）

1. 按参考文献列表顺序建立 `[Sx]→[n]` 映射（先现先得）。
2. 正文（参考文献段之前）`[Sx]→[n]`，合并引用 `[S1][S2]→[1][2]` 保持。
3. 删除脚手架标签 + 头部图例行。
4. 删除附录 A（**仅当位于参考文献段之后**；绝不能 `body.find('附录A')`——头部图例含"附录A"字样会截断全文）。
5. 清理封面占位、HTML 注释、`相关论断…详见附录A` 引导句。
6. 参考文献段 `[Sx]→[n]`；`--style gbt` 时同时去掉 ` URL: ` 前缀包装并追加 `[Sx]↔[n]` 对照表。
   - **注意**：`finalize_draft.py --style gbt` 只把**现有**参考文献段转成顺序编号骨架（`题名. 出版者, 年. URL`），不读取语料的作者/卷期页。
   - 需要完整 GB/T 7714（作者+卷期页+标准号）时，用 `build_references.py --style gbt` 从语料**重建**参考文献段（前提：语料已补 `authors`/`series` 字段），两者配合使用：先 `build_references.py --body` 重建，再 `finalize_draft.py` 净化。
7. 校验：残留标记=0、编号 1..n 连续、正文引用全覆盖、无重复 URL。
   - `--check` 忽略 `[Sx]↔[n]` 对照表段内的 `[Sx]`（该表是 gbt 模式刻意保留供投稿核查，投稿前删掉该节即可）。

## `[Gx]` 的学术化转换（定稿必做）

- 附录 A"证据缺口清单"不是终稿的一部分——正式论文把局限写进「研究局限/总结与展望」，不留内部标记。
- `finalize_draft.py` 自动完成：捕获附录A缺口表格 → 若正文引用了 `[Gx]`，在参考文献前插入 **`## 研究局限`** 小节（编号列表，取描述列），并把正文 `[Gx]` 标记删除；若正文无 `[Gx]` 引用，附录A直接删除。
- 人工检查：研究局限措辞应学术化（"因证据可得性与范围限制未予充分展开，有待后续工作补充"），与「总结与展望」呼应，可合并进第五章。

## 脚本无法覆盖的人工检查

- [ ] 封面学号、导师姓名、资助项目已填真实值（脚本只留占位）。
- [ ] 目录（Word 域/TOC）重新生成，含新增章节。
- [ ] 图号全文唯一且正文引述与图注一致（插入新图后连锁重编号）。
- [ ] 摘要/ABSTRACT 已同步新增章节内容。
- [ ] 参考文献条目符合 GB/T 7714：作者/卷期页码齐全、URL 去重、标题与标准号相符。
- [ ] 实证算例已用"公开文献参数演示算例"表述（无实堆数据时不得暗示真实电厂数据）。
- [ ] 期刊投稿版已删除 `[Sx]↔[n]` 对照表。

## 校验命令

```
python scripts/finalize_draft.py 11_定稿.md -o 11_定稿_clean.md --sources 04_validated_sources.json
python scripts/finalize_draft.py 11_定稿_clean.md --check      # 仅校验，不重写
python scripts/check_citations.py 11_定稿_clean.md --sources 04_validated_sources.json --min-sources 40 --min-chars 20000
```

## 常见坑（脚本已内置防护，手工清洗时须复读）

- **严禁** `re.sub(r'\s{2,}', ' ', text)`：会吞掉换行、摧毁整个 Markdown 结构。
- **严禁** 用 `text[ref_start:]` 引用旧切片：附录删除后再切，否则附录经旧切片回流。
- **必须** 对"参考文献段之后"的攻读学位/致谢等同样执行占位清理与注释删除（它们不在 body 切片内）。
