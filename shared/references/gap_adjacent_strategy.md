# Gap-Adjacent Evidence Splicing Strategy

## When to use

When evidence_map shows a G (gap) that is exactly the P (key problem)
the document is supposed to answer. No single source can directly support
the core argument. This is normal for research — the gap IS the topic.

## Steps

### 1. Recognize
Compare 06_evidence_map key_problems with evidence_gaps.
If any G matches a P semantically → trigger splicing strategy.

### 2. Decompose
Split the unresearched topic into 3-4 sub-questions that DO have
existing evidence in adjacent domains.

Example: "运动项目→幼儿游戏转化方法论" (G1)
├── Sub-1: Curriculum structure → LEG model [S15] (Curriculum Design)
├── Sub-2: Motor development patterns → Gallahue [S12] (Kinesiology)
├── Sub-3: Game design principles → [S4][S23] (Game Pedagogy)
└── Sub-4: Teacher role in instruction → SCT [S14] (Education)

### 3. Map
For each sub-question, identify ≥1 A-level source from an adjacent domain.
Document why the transfer is justified (shared mechanism, same population, etc.)

### 4. Splice
Combine frameworks from adjacent domains.
Mark ALL composite claims as `[假设]`.
In the document header, add: "本文核心理论框架为邻接领域证据拼接构建，标注[假设]的部分未经直接实证验证。"

### 5. Close
In the conclusion, include a transparent mapping table:

| Claim | Adjacent source | Transfer justification | Verification status |
|-------|----------------|----------------------|---------------------|
| 五环节模型 | LEG [S15] | Mirrors child motor learning stages | [假设], needs RCT validation |
| 分龄目标表 | 《指南》[S21] + DAP [S6] | Standards + development theory | [S21]部分可核实；拓展目标为[假设] |
| ... | ... | ... | ... |

## When NOT to use

- If any A-level source directly addresses the topic → use it directly, don't splice
- If the gap is a minor sub-claim (not a P1-P3) → accept as G, don't overbuild
- If the user explicitly forbids theoretical derivation → flag as unresolvable gap
