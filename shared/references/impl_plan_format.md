# 项目实施方案格式指南（Implementation Plan Format Guide）

> 从真实 CNPO《项目实施方案》样例（"氨+ETA"工艺 VVER 二回路应用研究）提炼，stage5 起草 `templates/plan_implementation.md` 时加载。区别于开题报告（proposal.md）：实施方案面向**已立项工程的执行组织**，不是立项论证。

## 一、文档结构（封面 + 修订记录 + 11 章）

| 部分 | 要点 |
|------|------|
| 编码封面 | 文件编码（脱敏占位）/文件总页数/编制部门/CFC 编写-校对-审核-批准栏/所有权声明 |
| 修订记录 | 版次/日期/章节/修订内容 |
| 目录 | 11 章带页码 |
| 1 项目背景 | 机组/系统背景 → 现有问题（机理链）→ 技术方向 → 本方案定位（一段"本方案是在……基础上，制定的具体试验方案"） |
| 2 依据及参考文件 | **三分类**：2.1 法律法规制度文件；2.2 依据文件（任务书/采购技术规格书）；2.3 检测标准文件（编号标准清单 + "未标注版本的均按最新版执行"声明） |
| 3 任务书工作内容及技术要求 | 3.1 工作范围及内容；3.2 专业技术要求（编号 1)~N)，逐条可验收） |
| 4 应用研究现状 | 机理性质（公式+数据表）→ 国内外应用情况 → **末节收束"需研究的问题"** |
| 5 项目总体实施技术路线 | 一图（流程图）+ 总体思路 |
| 6 项目具体实施方案 | 每项试验/工作一小节（6.1~6.N）：目的→材料/对象→工况参数→方法步骤→评价指标→与氨对比 |
| 7 项目组织机构 | 7.1 人员和分工（角色职责清单）；7.2 内外部接口管理 |
| 8 进度计划 | 表格：序号/工作内容/成果形式/完成时间（D0+X 月相对基准） |
| 9 项目成果 | 交付文件清单（> 列表）+ 知识产权成果表（专利/论文） |
| 10 职业安全健康和环境管理体系 | 体系范围/安环体系/实验室管理 |
| 11 项目验收 | 编号验收条件（与第 3 章技术要求呼应） |

## 二、编号与写作规范

- **图表公式按章编号**（图1-1、表4-1、式(4-1)）——区别于 GF 报告的全文顺次编号。
- 公式居右编号，"式中，X 为……"符号说明；表格三线/网格均可，表题在上、图题在下。
- 首行缩进两字符；章标题"1 项目背景"式（数字+空格+名词短语），小节 1.1/1.1.1。
- 依据章标准清单只列编号+名称，现行性声明统一写"如修订适用最新有效版本"；[Sx] 标注附于条目。
- 任务书条目**逐条可验收**（量化指标/对比对象/交付物），禁止空泛"开展研究"。
- 进度用相对基准（D0+X 月），成果形式与第 9 章交付物一一对应。
- [Sx] 贯穿正文（工程方案非法律文本）；机组参数/任务书数值/试验数据 → [待内部确认]。
