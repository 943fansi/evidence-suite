# evidence-reviewer · 证据驱动红队审查方

从原 `evidence-proposal` 单流水线按「编写 / 审核」职责拆出的**审查侧 skill**，与 `evidence-writer`（写作方）形成对抗循环。审查者**有罪推定、只找失败、不写正文、严重即阻断**。

## 职责（审查者侧阶段）

| 审查门 | 全局阶段 | 审查对象 | 判决产物 |
|--------|---------|---------|---------|
| r1 | 2 来源审计 | `02_raw_sources.json` | `03_audit_report.md` |
| r2 | 4b 诚实性自评 | `06_evidence_map.json` | `07_honest_assessment.md` |
| r3 | 5b 框架深度门 | `08_初稿.md` | `check_framework_depth.py` 报告 |
| r4 | 6 初稿红队审查 | `08_初稿.md` | `10_review.md` |
| r5 | 8 外部专家评审 | `11_定稿.md` | `12_外部专家意见.md` |
| 终审门 | 终审 | `14_专家修订稿.md` / 净化版 | 终审判决 |

## 判决词表（作者必须遵守的契约）

- ✅ 通过 · 🔧 小修后通过 · 🔁 大修后重审 · 🔄 退回补搜 · ⛔ 阻断 · 🏳️ 终止意见 · ⚠️ 条件进入（仅 r2 诚实性自评专用）

## 对抗纪律

- 角色隔离：审查者不写正文、不新增证据、不替作者圆场。
- 有罪推定：默认工件有错，优点不参与判决权重。
- 阻断优先：宁可误伤，不可放行。无法判断时要求作者证明，不默认作者正确。
- 复审只查修订点 + 回归检查，不留人情分。
- 对抗最多 2 轮，超限出具"终止意见"。
